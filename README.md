## Описание проекта
Проект представляет собой веб-приложение - онлайн-магазин одежды, разработанный на базе фреймворка Django.

Для проекта выбрана и добавлена лицензия MIT.

### Используемые языки, библиотеки и технологии
#### Языки программирования и разметки:
- Python (основной язык backend-разработки).
- HTML (шаблоны представлений).
- SQL (взаимодействие с реляционной базой данных).

#### База данных:
- PostgreSQL (локально установленный сервер и облачная БД на хостинге).

#### Ключевые библиотеки и фреймворки (Python):
- Django - основной веб-фреймворк для построения архитектуры приложения.
- psycopg2 - драйвер для подключения Django к базе данных PostgreSQL.
- dj-database-url - библиотека для парсинга URL базы данных (используется для гибкой настройки локального окружения и облачной среды).
- Gunicorn и Uvicorn - WSGI/ASGI серверы для запуска приложения в производственной среде (production).
- WhiteNoise - библиотека для раздачи статических файлов (CSS, JS) напрямую через веб-сервер приложения.

#### Инструменты CI/CD и развертывания:
- Git и GitHub (контроль версий).
- Render - облачная PaaS-платформа, выбранная в качестве альтернативы Heroku, обеспечивающая автоматическое развертывание (CI/CD) из репозитория.


### Тестирование: 
Написано 14 модульных тестов, покрывающих работу моделей, представлений и бизнес-логику расчета скидки. Тесты проверяют как успешные сценарии, так и граничные случаи (например, попытка оформить пустой заказ). Все тесты успешно пройдены.

### CI/CD и Деплой: 
Настроено автоматическое развертывание приложения в облаке на платформе Render. При каждом пуше в удаленный репозиторий GitHub платформа автоматически запускает скрипт build.sh, который устанавливает зависимости, собирает статику, применяет миграции к облачной БД и перезапускает сервер.
